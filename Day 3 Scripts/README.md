# Day 3 — Sampling, Distributions & A/B Testing

Wednesday 9 September 2026. Covers sampling from populations, comparing observed data against model distributions, and using simulation to test hypotheses.

| Session | Notebook | Topic |

| 3 | `SUN_DS-Python_Workshop_Day3_Session3.ipynb` | Comparing Distributions, Decision & Uncertainty — product defects example, distance between distributions |
| 4 | `SUN_DS-Python_Workshop_Day3_Session4.ipynb` | A/B Testing — comparing two samples, test statistics, random permutation (shuffling) |
